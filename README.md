# Surf LR - DEVZONES GEREKLİDİR!
Bu eklenti surf_ski_2_go haritasında trollsüz, kurallı lr atmanıza yarayan bir eklentidir. !lr ile menü açılır menüden biri seçilir ve ona istek gönderilir. isteği kabul ederse mariodaki lr odasına ışınlanırlar ve orda lr atarlar. Ses efekti mevcuttur.

# Kurulum
İndirdiğiniz klasördeki surf_lr.smx dosyasını addons/sourcemod/plugins kısmına atın.<br/>
Sound klasöründeki lrsarki.mp3`ü sound/Plugin_Merkezi/Surf_LR/lrsarki.mp3 klasörüne atın.
